# 决策模拟器 (Decision Simulator)

一个功能强大且美观的决策辅助工具，提供多种随机决策方式，帮助你在犹豫不决时做出选择。

## ✨ 功能特色

### 🪙 抛硬币 (Coin Flip)
- **功能**: 经典的正反面抛硬币决策
- **特性**: 
  - 3D翻转动画效果
  - 支持自定义正面和反面的内容
  - 流畅的物理模拟
- **使用场景**: 二选一的简单决策，如"去还是不去"、"买还是不买"

### 🎲 掷骰子 (Dice Roll)
- **功能**: 掷骰子生成随机数
- **特性**:
  - 支持多种骰子类型：D4、D6、D8、D10、D12、D20、D100
  - 支持同时掷1-6个骰子
  - 显示每个骰子的点数和总和
  - 动态滚动动画
- **使用场景**: 需要数字决策、游戏、随机分配任务

### 🎯 转盘 (Spinner Wheel)
- **功能**: 彩色转盘随机选择
- **特性**:
  - 支持自定义多个选项（最少2个）
  - 动态添加/删除选项
  - 华丽的旋转动画（持续3秒）
  - 多彩的分区显示
- **使用场景**: 多人抽签、选择餐厅、决定活动内容

### 📋 随机选择 (Random Picker)
- **功能**: 从列表中随机选择一项
- **特性**:
  - 支持批量输入选项（每行一个）
  - 快速切换动画效果
  - 清晰的结果展示
- **使用场景**: 从多个备选方案中选择、随机点名、抽奖

### ✨ 神谕 (Oracle)
- **功能**: 魔法8球式的是非问答
- **特性**:
  - 输入问题获得建议性答案
  - 16种不同类型的回答（积极、中性、消极）
  - 神秘的水晶球动画效果
  - 摇晃动画模拟真实体验
- **使用场景**: 寻求建议、犹豫不决时的参考、娱乐互动

## 🎨 设计亮点

- **美观的UI**: 使用 Tailwind CSS 和 shadcn-vue 组件库，确保视觉效果一流
- **流畅动画**: 集成 @vueuse/motion 动画库，提供丝滑的交互体验
- **响应式设计**: 完美适配桌面和移动设备
- **即时反馈**: 使用 toast 通知显示结果
- **直观操作**: 所有功能都设计为一键操作，简单易用

## 🚀 使用方法

1. **选择决策模式**: 点击顶部的五个图标卡片选择你需要的决策方式
2. **自定义设置**: 根据需要自定义选项内容、骰子类型等
3. **开始决策**: 点击对应的按钮开始随机决策
4. **查看结果**: 等待动画完成，结果会以醒目的方式展示

## 📦 技术栈

- **Vue 3**: 现代化的前端框架
- **TypeScript**: 类型安全的开发体验
- **Tailwind CSS**: 实用优先的CSS框架
- **shadcn-vue**: 高质量的Vue组件库
- **@vueuse/motion**: 强大的动画库
- **lucide-vue-next**: 精美的图标库

## 🎯 应用场景

- 日常生活决策：选择吃什么、去哪玩
- 团队活动：分配任务、选择方案
- 游戏娱乐：TRPG骰子、聚会游戏
- 随机抽签：抽奖、点名、分组
- 寻求建议：犹豫不决时的参考

## 💡 提示

- 所有决策结果都是完全随机的，基于JavaScript的Math.random()
- 可以多次尝试直到得到满意的结果
- 转盘模式建议添加3-8个选项效果最佳
- 神谕模式的答案仅供娱乐参考，重要决策请理性思考
